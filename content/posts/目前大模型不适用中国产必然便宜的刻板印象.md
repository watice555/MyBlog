# 现状

常见的刻板印象是，一种产品从发达国家生产转向中国生产时，价格会大幅下跌，成为白菜价，很多产品，包括所谓的新兴产业和工业明珠，都符合这一规律。

但目前大模型并不符合这一刻板印象。GLM，Kimi等国产领先模型，尽管在性能上已经逼近了领先的GPT和Claude模型，但计算实际使用价格时，却并没有优势。综合考虑性能和价格，反而是GPT和Claude性价比更高。

以GLM为例，套餐价格如下：
- ¥118/月，每周 10,000 积分
- 模型消耗积分数 = （输入 Token × Input 抵扣系数 + 缓存命中 Token × Cached Input 抵扣系数 + 输出 Token × Output 抵扣系数） / 10000

| 模型                       | Input 抵扣系数 | Cached Input 抵扣系数 | Output 抵扣系数 |
| ------------------------ | ---------: | ----------------: | ----------: |
| GLM-5.3                  |        6.9 |               1.7 |          24 |
| GLM-5.3-Flash（含视觉理解 MCP） |        2.3 |              0.56 |           8 |

同时 API 价格为：
| 模型            | Input | Output | Cache Hit |
| ------------- | ----: | -----: | --------: |
| GLM-5.3       |     8 |     28 |         2 |
| GLM-5.3-Flash |   0.8 |    2.8 |      0.23 |

因此，每周积分等效额度为：

| 模型                | 全 Input | 全 Cache hit | 全 Output |    大致等效 API 额度 |
| ----------------- | ------: | ----------: | -------: | -------------: |
| **GLM-5.3**       | ¥115.94 |     ¥117.65 |  ¥116.67 | **≈ ¥116–118** |
| **GLM-5.3-Flash** |  ¥34.78 |      ¥41.07 |   ¥35.00 |   **≈ ¥35–41** |

这样，订阅套餐相比于 API ，使用 GLM-5.3 时有约 420% 的使用量，使用 GLM-5.3-Flash 时仅有约 134% 。

而 GPT/Claude 的订阅套餐往往有 2000-4000% 相对于 API 的使用量。这样，尽管 API 层面 GPT/Claude 的价格要贵出 3 倍，实际使用中反而可能更便宜。

# 原因

要问为什么大模型领域是个例外，首先要问为什么中国产往往能打到白菜价。

主要原因是，中国低廉的人力成本；以及在大学大力扩招以后，低廉的工程师成本。

完善的工业体系之类的，自然也有影响，但是第二性的。

但大模型领域，推理的主要成本并非人力，而是算力，是计算卡。

中国大模型厂商无法通过合法渠道购买领先的英伟达算力卡。非法渠道自然面临着更高的风险，高额的溢价以及供应的不确定性。而国产算力卡则面临着落后和更低性价比的情况。

具体来说，华为对战英伟达，按照梁文锋的说法，是“四张顶一张，落后两年”。而华为在国产里已经是最强的那位了。

当然，国产卡今天发展到能用但性价比差的水平，已经很不错了。

不过，在国产算力卡的性价比赶上英伟达之前，大模型领域会是反直觉的，美国厂商对中国厂商打价格战。
