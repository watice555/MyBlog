> 眼尖的人发现富国全球科技偷偷买了半仓港股，那么究竟买了什么呢？本文试图揭秘这一问题。

# 富国全球科技互联网股票（QDII）2026年二季度未披露持仓反推报告

## 一、结论摘要

截至2026年6月30日，该基金：

- 基金资产净值约 **184.36亿元**；
- 直接股票仓位占净值 **92.25%**；
- 前十大股票合计占净值 **47.465%**；
- 十大以外股票合计占净值 **44.782%**；
- 十大以外股票中，按精确金额计算：
  - **港股约44.685%**
  - **A股约0.097%**
  - **美股、韩国、日本均为0**

因此，二季度末没有未披露的美股、韩国股或日本股；所有美股、韩国股和日本股均已完整出现在前十大中。未披露组合几乎全部是港股。

按行业倒推，十大以外股票包括：

- 信息技术：**19.844%**
- 通信服务：**9.938%**
- 可选消费：**7.897%**
- 原材料：**4.372%**
- 工业：**2.656%**
- 医疗保健：**0.069%**
- 公用事业：**0.005%**

由于第十大西部数据的精确权重约为 **4.224%**，任何未进入前十的单只股票原则上不能高于这一比例。按各行业分别计算，十大以外至少需要 **15只股票**；其中至少约 **13只为港股**。实际持仓数量大概率高于这个数学下限。

具体标的方面，置信度最高的未披露候选是：

1. 网易云音乐、腾讯、快手；
2. 阿里巴巴，并可能搭配美团、京东、携程；
3. 中芯国际、中兴通讯、小米、时代互联、联想、丘钛科技等港股硬件公司；
4. 创新实业集团、紫金黄金国际；
5. 少量工业、医疗新股及其他小仓位。

# 三、可参考线索

## 3.1 二季度投资策略提供的方向性线索

基金经理明确披露了七项调整：

1. 提高DRAM、NAND和HBM配置，存储成为前十大主要方向；
2. 新增大容量机械硬盘；
3. 保留先进封装设备；
4. 新增AI服务器覆铜板；
5. 对GPU、大型云平台和晶圆代工进行获利了结及再平衡；
6. 对服务器CPU和光刻机进行获利了结；
7. 中国互联网平台因基金规模增长、增量资金更多投入存储而被动降低权重，退出前十大，但基金经理并未转为看空中国互联网。

其中前六项基本都已由前十大解释：

| 策略描述 | 前十大对应标的 |
|---|---|
| HBM、DRAM | SK海力士、三星、美光、兆易创新 |
| NAND | SanDisk、铠侠、美光、三星 |
| HDD | 希捷、西部数据 |
| 先进封装 | ASMPT |
| 覆铜板 | 生益科技 |
| 卖出GPU、云平台、CPU、光刻机 | 对应一季度英伟达、谷歌、AMD、英特尔、ASML等退出 |

因此，二季度策略文字中真正能够直接指向“十大之外”的主要是：

- 中国互联网平台仍然保留；
- 港股信息技术中可能还有多只非核心仓位；
- 原材料和工业行业存在报告策略未详细解释的其他持仓。

# 四、十大以外持仓的基准情景推演

## 4.1 推演方法

以下比例均指占基金净值的比例。

推演遵循四项原则：

1. 每个行业必须与官方披露的行业余额闭合；
2. 所有港股行业合计必须等于44.685%；
3. 任一单只候选不得超过约4.224%；
4. 优先使用过往期末真实持仓、2025年交易记录和二季度策略文字，而不是单纯按产业链寻找股票。

下表中的“基准比例”是一组满足全部约束的中性情景，不代表对实际比例的精确预测。

网易云音乐的置信度最高，因为：

- 2025年末为8.87%；

如果网易云音乐二季度末已经完全卖出，基金经理关于“被动下降并退出前十大”的解释会较难成立。

腾讯和快手在2025年末均为大仓位，也是基金经理所称“社交、短视频平台”的直接映射，因此保留部分仓位的概率较高。

# 六、置信度与主要限制

## 可以视为确定的结论

1. 十大以外股票总权重为44.782%；
2. 其中港股约44.685%，大陆股票约0.097%；
3. 没有十大以外的美国、韩国或日本直接股票；
4. 十大以外信息技术约19.844%、通信服务约9.938%、可选消费约7.897%；
5. 未披露股票至少15只；
6. 中国互联网平台仍然存在于组合中的概率很高。

## 不能确定的部分

1. 19.75%的港股信息技术究竟由哪些公司组成；
2. 互联网平台之间的具体权重分配；
3. 原材料是否只有创新实业和紫金黄金国际两只；
4. 约2.66%的工业股是集中于一只还是分散于多只；
5. 0.097%的A股和极小医疗、公用事业仓位的具体名称。

因此，个股基准比例的价值主要是展示一组**能够在数学上闭合、且与历史持仓相容的组合**，不能替代完整中期报告的期末持仓明细。
